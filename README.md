# Simple Python Calculator

This is a simple command-line calculator I built to practice Python.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/) with a zero-division check

## How to Run

```bash
python calculator.py
```

## Example Output

```text
Enter first number: 10
Enter operator: +
Enter second number: 5
15.0
```
